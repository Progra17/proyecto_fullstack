Para la carpeta backend se realizaron los siguientes comandos:
npm init -y
npm install express
npm install cors
npm install mysql

Para establecer conexion de manera correcta con el servidor, mysql indica el siguiente error:
code: 'ER_NOT_SUPPORTED_AUTH_MODE',
  errno: 1251,
  sqlMessage: 'Client does not support authentication protocol requested by server; consider upgrading MySQL client',
  sqlState: '08004',
  fatal: true
Se debe ejecutar lo siguiente en la linea de comandos de Mysql o en una consulta de MySql Workbench lo siguiente:
ALTER USER 'root'@'localhost' IDENTIFIED WITH mysql_native_password BY 'contraseña del usuario';
FLUSH PRIVILEGES;

Para la carpeta frontend se realizaron los siguientes comandos
npx create-react-app proyecto_fullstack
npm install axios
npm install react-router-dom


--- DOCKER ---
Se crean los archivos "Dockerfile" tanto en frontend como backend
Se crea el archivo docker-compose.yml con la configuracion del entorno
Se crean los archivos .dockerignore tanto en frontend como backend para evitar cargar las variables de entorno
que se cargan cuando se hace npm install

Desde MySQL Workbench se exporto la informacion que ya se tenia guardada Server -> Data export -> Se selecciona la BD 
(fullstack) -> Se marca la opcion "Export to Self-Contained File" -> Export progress -> Start export

Se crea una carpeta en el proyecto mysql/init y aqui se guarda el archivo creado con la opcion "Export to self..."

En la raiz del proyecto se corre el comando "docker compose up --build" esto crea el contenedor y lo levanta
